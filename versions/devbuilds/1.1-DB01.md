# Halo: GoldSource - Winter 2025 Update (v1.1-DB01)
# Changelog
## Additions
- Switched to the Aura codebase.
	- Aura is the codebase for multiplayer Half-Life 1 mods we have been using since 2021. Until now, it was only being used for *Cross Product Multiplayer* - we have rewritten the legacy HaloGS SDK code in Aura, meaning there's more room now for expandibility.

## Aura codebase
Thanks to the use of the Aura codebase, we have:
- Added a gamemode system. When you start a server, or in the console, type the gamemode's name (such as `slayer`). This also adds the following gamemodes:
	- Capture the Flag (`ctf`)
	- CTF Rounds (`ctf2`)
	- Territories (`territories`)
	- Fiesta (`fiesta`)
	- Firefight (`firefight`)
	- Fiestafight (`fiestafight`)
	- Slayer (`slayer`)
	- Special Weapons & Tactics (`swat`)
	- Snipers (`snipers`)
	- Swords (`swords`)
	- Team Slayer (`tslayer`)
	- Team Snipers (`tsnipers`)
	- Team SWAT (`tswat`)
- Added a way to dynamically change flag positions, spawn points, control points, and more in CTF&DOM when in a LAN server.
- Many maps (except the Firefight ones) now have CTF&DOM support.
- Added many helpful options & controls to both Multiplayer Advanced and the Controls page respectfully.
- Backported the **Command Menu** from TFC which lets you run handy options mid-game such as voting, changing the gamemode, changing teams, etc.

## Changes
- Tuned the weapon balancing. Precision weapons such as the Sniper Rifle and the Energy Sword are now as effective as they are in Halo, et al.
- Following the above change, you no longer start with the Energy Sword. It now must be found within the map.
- The HUD now scales properly when playing on higher resolutions.
- Fixed the viewbob changing direction depending on which way the player is facing.
- Fixed the Shotgun playing a pump sound when it finished reloading.
- Fixed many sounds continuing to play in low-quality.
- Fixed the menu music overlapping the intro video.
- The menu music now plays again when you disconnect from a server.
- The Firing Range is now set at day-time, and you no longer lose any reserve ammunition.
- Added missing weapons to the Firing Range.
- Fixed a bug in Chiron where players could clip out of bounds.
- Fixed muzzle flashes not appearing on some weapons.
- All maps with teleporters now use the proper teleport sound from Halo.
