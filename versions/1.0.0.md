# Halo: GoldSource - Summer 2025 Release | `1.0`
## Changelog
### Additions
- Halo-like jumping behaviour
- Modern viewbobbing and viewmodel lag
- Proper suit/armour regeneration
- Added some options to Settings > Multiplayer > Advanced. More to come!
- Added mapcycle.txt, which goes through every map in the game.
- Enabled basic controller support.
    - **Note:** Enhanced Controller Support is not yet implemented, meaning vibration & Light Bar support will not work.
- Linux support!

### Changes & Fixes
- Enhanced VGUI elements
- Fixed a bug where the menu would crash when running the game in 4K
- HUD weapon selection sounds
- High-definition sound design
- The Assault Rifle, Sniper Rifle and Covenant Carbine viewmodels no longer clip through the camera

### Removals
- Removed forced-music
