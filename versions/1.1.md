# Halo: GoldSource - Winter 2025 Update (v1.1)
# Changelog
## 🆕 Additions
- Switched to the Aura codebase.
	- Aura is the codebase for multiplayer Half-Life 1 mods we have been using since 2021. Until now, it was only being used for *Cross Product Multiplayer* - we have rewritten the legacy HaloGS SDK code in Aura, meaning there's more room now for expandibility.

## ⚙️ What is the Aura codebase?
Thanks to the use of the Aura codebase, we have:
- Added a gamemode system. They can be selected in the new **Custom Game Composer**. Or in the console, type the gamemode's name (such as `slayer`). The following gamemodes have been added:
	- Arcade (`arcade`)
	- Capture the Flag (`ctf`)
	- CTF Rounds (`ctf2`)
	- Fiesta (`fiesta`)
	- Firefight (`firefight`)
	- Fiestafight (`fiestafight`)
	- Instant Gib (`instagib`)
	- Last Spartan Standing (`lss`)
	- Last Team Standing (`lts`)
	- Lone Wolves (`lwolves`)
	- Rockets (`rockets`)
	- Slayer (`slayer`)
	- Snipers (`snipers`)
	- SWAT (`swat`)
	- SWATnums (`swatnums`)
	- Swords (`swords`)
	- Territories (`territories`)
	- Team Arcade (`tarcade`)
	- Four-Team Arcade (`tarcade4`)
	- Team Fiesta (`tfiesta`)
	- Team Slayer (`tslayer`)
	- Four-Team Slayer (`tslayer4`)
	- Team Snipers (`tsnipers`)
	- Team SWAT (`tswat`)
	- Team SWATnums (`tswatnums`)
- Added a new **Custom Game Composer**, which replaces the old **Create Server** dialog. Easily set a Map & Gamemode with this new ergonomic UI.
- All the built-in maps, excluding the Firefight ones, now have CTF&DOM support.
- Added many helpful options & controls to both Multiplayer Advanced and the Controls page respectfully.
- Backported the **Command Menu** from TFC which lets you run handy options mid-game such as voting, changing the gamemode, changing teams, etc.


## 🛠️ Changes
- Tuned the weapon balancing. Power weapons such as the Sniper Rifle and the Energy Sword are now as effective as they are in Halo, et al.
- Following the above change, you no longer start with the Energy Sword. It now must be found within the map.
- The HUD now scales properly when playing on higher resolutions.
- Fixed the viewbob changing direction depending on which way the player was facing.
- Fixed the Shotgun playing a phantom pump sound after it had finished reloading.
- The Shotgun viewmodel is now properly centered.
- Fixed many sounds continuing to play in low-quality.
- Fixed the menu music overlapping the intro video.
- The menu music now plays again when you disconnect from a server.
- The Firing Range is now set at day-time, and you no longer lose any reserve ammunition.
- Added missing weapons to the Firing Range.
- Fixed a bug in Chiron where players could clip out of bounds.
- Fixed muzzle flashes not appearing on some weapons.
- All maps with teleporters now use the proper teleport sound from Halo.
- Mitigated performance issues on Blood Gulch.
- Redesigned the main menu to look similar to **original Halo 3.**


## 🚫 Removals
- Removed the airstrike from Blood Gulch.
